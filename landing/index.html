GitHub에서 바로 ‘와플코드로 열기’

Visual Studio로 열기처럼, 클릭 한 번으로 내 컴퓨터의 WaffleCode가 켜지며 저장소를 클론하고 개발을 시작합니다.

100% 합법 & 표준 Custom URL Protocol

VS Code(vscode://), Cursor(cursor://), GitHub Desktop(x-github-client://)과 완벽히 동일한 방식으로 wafflecode:// 공식 프로토콜을 사용합니다.

💡 확장 프로그램을 꼭 깔아야 하나요? (심사 기간/설치 번거로움 해결)

전혀 필수가 아닙니다! GitHub 본사 사이트의 <> Code 드롭다운 메뉴 '내부'에 글자를 끼워 넣으려면 브라우저 확장이 필요하지만, WaffleCode 프로그램만 설치하면 PC에 프로토콜이 자동 등록되므로 아래 방법들로 확장 프로그램 없이도 1초 만에 즉시 열 수 있습니다:

  • ① README 원클릭 배지 (가장 추천): 저장소 문서의 배지를 누르면 확장 프로그램 없이도 컴퓨터의 WaffleCode가 즉시 실행됩니다.
  • ② 북마클릿 (심사/설치 0초): 아래 [⭐ 북마클릿] 버튼을 브라우저 북마크 바에 끌어다 놓으면, 어떤 GitHub 페이지에서든 클릭 한 번으로 즉시 열립니다.
  • ③ URL 붙여넣기: GitHub 주소 복사 후 WaffleCode에서 바로 열기.
  • ④ 크롬/엣지 확장 프로그램 (선택 사항): <> Code 메뉴 안에 버튼을 꼭 넣고 싶은 분들을 위한 보조 옵션입니다.
